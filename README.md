# Autoprod demos

Short product demos for Autoprod's browser apps.

- **Prepline** – kitchen prep list organiser: https://autoprod-dev.github.io/preplist-sorter/
- **Unifile** – convert files in the browser: https://autoprod-dev.github.io/unifile/

The store review demo video (MP4, 1080p, about 1.5 minutes, captions, no audio) is attached to the
[Store review demo](../../releases) release. It shows Prepline's built-in sample menu (made-up data),
Prepline Pro pricing, checkout and licence activation in Lemon Squeezy **test mode**, and a Unifile sample conversion.
